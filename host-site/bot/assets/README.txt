لوگوی سایت برای واترمارک کاورها
================================

logo.png       لوگوی اصلی: PNG با زمینه‌ی شفاف، ترجیحاً تک‌رنگ سفید، عرض ۶۰۰ پیکسل یا بیشتر، بدون حاشیه‌ی اضافی
               (حاشیه‌ی شفاف دور لوگو خودکار حذف می‌شود).
               حالت پیش‌فرض (سبک رادیوجوان): لوگو وسط یک پلاک رنگی با گوشه‌ی گرد می‌نشیند؛ رنگ پلاک برای هر کاور
               از رنگ غالبِ پررنگ همان کاور گرفته می‌شود. لوگوی مربعی (مثلاً آیکن + نام زیر آن) → پلاک مربع،
               لوگوی کشیده (نوشته‌ی افقی) → پلاک مستطیل.
logo-dark.png  اختیاری: همان لوگو به رنگ تیره؛ وقتی پلاک (یا در حالت بدون پلاک، گوشه‌ی کاور) روشن باشد به‌جای سفید می‌نشیند.
               اگر نباشد، پلاک روشن کمی تیره‌تر می‌شود تا لوگوی سفید خوانا بماند.

تنظیمات (جای لوگو، اندازه، شفافیت، سایه، پلاک و رنگ آن): host-site/bot/config.php → $bot_watermark_*
بدون پلاک (لوگوی آزاد با سایه مثل قبل): $bot_watermark_plate = 'none'؛ رنگ ثابت: $bot_watermark_plate_color = '#1e1e1e'
پیش‌نمایش و اجرای دسته‌ای روی کاورهای قدیمی: https://ahangban.ir/bot/watermark-batch.php
همین دو فایل را در hostdl/assets/ روی هاست دانلود هم بگذارید (کاور داخل فایل‌های MP3).
